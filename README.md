# Banking Customer Analytics Dashboard

A Power BI dashboard designed to analyze banking customer behavior, transactions, satisfaction, churn probability, customer lifetime value, risk groups, and acquisition channels.

## Tools Used

- Power BI
- Python
- Pandas
- NumPy
- Excel

## Dashboard Analysis

- Customer Segmentation
- Transaction Analysis
- Customer Satisfaction
- Churn Probability
- Customer Lifetime Value (CLV)
- Risk Group Analysis
- Acquisition Channel Analysis
- Customer Age Distribution

## Project Overview

This project transforms banking customer data into interactive visual insights using Power BI. The dashboard helps explore customer segments, transaction patterns, satisfaction levels, churn probability, CLV, risk groups, and acquisition channels.
